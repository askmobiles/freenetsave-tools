How to use it

  1. Choose your Word file (.docx) or drop it on the box.
  2. Check the preview.
  3. Tap Save as PDF. In the print window, choose Save as PDF as the printer, then save.

Common questions

Is my document uploaded?

No. The file is opened by your own browser on your device. Nothing is sent to us or anyone.

Will it look exactly like in Word?

Text, headings, lists, tables and pictures come across. Special layouts like text boxes, columns, page borders, headers and footers may look simpler. For an exact copy, use File → Save As → PDF inside Word.

Can I use an old .doc file?

Not directly. Open it in Word or Google Docs and save it as .docx first.
