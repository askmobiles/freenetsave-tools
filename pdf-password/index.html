How to use it

  1. Choose your PDF.
  2. Type a password twice. Choose if people may print or copy text.
  3. Tap Lock and download. Share the password separately, for example by phone or text.

Common questions

Is my PDF uploaded?

No. The file is locked by your own browser on your device. We never see your file or your password.

How strong is the lock?

It uses AES-256, the strongest standard PDF lock. A long password (12+ characters) makes it very hard to break.

I forgot the password

We cannot help, because we never see it. Keep the original unlocked file somewhere safe.

Will it open on any device?

Yes. Adobe Reader, phone and computer PDF viewers and web browsers ask for the password and open it.
